# tcga-dbt

Analytical pipeline for TCGA-BRCA (breast cancer) data. Raw genomic and clinical data is pulled from the NCI GDC into DuckDB using R, then transformed into analysis-ready tables using dbt.

## Structure

```
tcga-dbt/
├── extraction/   # R project — pulls from GDC, writes raw tables to DuckDB
├── transform/    # dbt project — builds staging and mart models on top of DuckDB
└── data/         # shared DuckDB file (gitignored, generated by extraction)
```

The two sides are decoupled. The only contract between them is the DuckDB file at `data/tcga_brca.duckdb` and the three tables it must contain: `raw.clinical`, `raw.maf`, `raw.rna_expression`.

## Quickstart

**Step 1 — extract**

```bash
cd extraction
Rscript extract_tcga.R
```

This writes ~1,100 clinical records, ~90k somatic mutations, and ~600k RNA-seq rows into `data/tcga_brca.duckdb`. See [`extraction/README.md`](extraction/README.md) for prerequisites and scale controls.

**Step 2 — transform**

```bash
cd transform
uv run dbt run --profiles-dir .
```

See [`transform/README.md`](transform/README.md) for dbt setup details.

## Data sources

| Table | Source | Access |
|---|---|---|
| `raw.clinical` | GDC clinical endpoint (`TCGA-BRCA`) | Open |
| `raw.maf` | Masked Somatic Mutation, Aliquot Ensemble workflow | Open |
| `raw.rna_expression` | Gene Expression Quantification, STAR - Counts | Open |
