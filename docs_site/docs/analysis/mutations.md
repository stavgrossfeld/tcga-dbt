## SNV Class

C>T transitions dominate — consistent with APOBEC mutagenesis and age-related deamination, both known signatures in BRCA.

## Tumor Mutation Burden

- **Median TMB:** ~1 mut/Mb
- **Distribution:** Log-normal, centered around 0.5–2 mut/Mb

BRCA is a low TMB cancer type. For comparison, melanoma median is ~10–15 mut/Mb.
